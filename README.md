# CodeIQ Dev

CodeIQ Dev is an AI-powered developer CLI toolkit designed to accelerate your development workflows.

## Features
- **AI Response Generation**: Ask coding questions and get fast responses directly in your terminal.
- **Automated Conventional Commits**: Inspect staged Git diffs and generate clean conventional commit messages automatically.
- **Git Workflow Integration**: Simplify daily Git actions seamlessly with terminal status spinners and rich formatting.

## Quick Start
```bash
pip install -e .
codeiq commit
```
